3. EXTENSION STRUCTURELLE MINIMALE
---------------------------------

Le premier contrôle après import a montré que le TEI, le schéma générique, les
tests et le build acceptaient la balise fw, mais que le parseur l’ignorait dans
les données du lecteur. La réclame n’était donc pas visible dans les trois modes.

Conformément aux instructions v1.0, seule l’extension technique minimale a été
appliquée :
- type distinct pour une réclame ;
- prise en charge de fw[@type="catchword"] dans l’ordre du flux TEI ;
- conservation séparée des lignes du corps ;
- validation de son type, de son xml:id et de son contenu ;
- comptage structurel catchword dans le manifeste ;
- affichage distinct sous le corps dans les trois modes ;
- indication explicite, en mode modernisé, que la forme affichée n’est pas
  modernisée par le TEI ;
- règle Relax NG explicite ;
- test de non-régression dédié.

Aucun caractère du TEI éditorial n’a été modifié.
